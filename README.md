# MondoLens knowledge packs

Regional SQLite (FTS5) dish packs for the MondoLens offline menu reader, published as release assets.
The app ships these packs inside its binary and only downloads a newer release over Wi-Fi when the user asks.

Each release holds one `.db` per region and a `manifest.json` (URL, size, SHA-256, version).

Data: entries written for MondoLens, plus Wikidata (CC0).
